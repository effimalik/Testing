ap2_accLog — live cache

This reads the ap2_accLog IndexedDB cache the same way upLog.html reads ap2_loginData — via the shared cacheWatcher, or a direct IDB read / parent postMessage if that script isn't available. Rows never get deleted here: an expired record just stops being picked by the resolver and stays visible in the Full Log for future reference.

Expected row shape per entry in ap2_accLog's cached array (7 columns):

[ EID, AccType, AccountNo, AddDetail, Comment, StartDate(DDMMYYYYHHMMSS), ExpDate(DDMMYYYYHHMMSS) ]

If your sheet's real column order differs, adjust mapRawRow() near the top of the script — everything downstream (resolver, batch, log) just consumes the normalised record.
