ap2_accLog — live cache

This reads the ap2_accLog IndexedDB cache the same way upLog.html reads ap2_loginData — via the shared cacheWatcher, or a direct IDB read / parent postMessage if that script isn't available. Rows never get deleted here: an expired record just stops being picked by the resolver and stays visible in the Full Log for future reference.

Expected row shape per entry in ap2_accLog's cached array (7 columns):

[ AccountNo, AccType, EID, AddDetail, Comment, StartDate(DDMMYYYYHHMMSS), ExpDate(DDMMYYYYHHMMSS) ]

If your sheet's real column order differs, adjust mapRawRow() near the top of the script — everything downstream (resolver, batch, log) just consumes the normalised record.

Which account is active right now?

Pick a mode. For each EID, the resolver first looks for a special / timed account (any AccType with both a StartDate and an ExpDate) that is valid today — if one exists, it wins regardless of type. Otherwise it falls back to that EID's plain ${MODE} account (no expiry, or an expiry that just hasn't been reached). Advance additionally falls back to Salary if no Advance account exists at all. Anything with no valid account for the mode is skipped here (it's still in the Full Log).
