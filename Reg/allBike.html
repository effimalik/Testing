Upload / Update Bikes

Upload a CSV to add new bikes. Rows with a plate number that already exists will be skipped. Use Download Template for correct columns.
Upload a CSV to update existing bikes. Match is done by Plate Number. Only non-empty columns in your CSV will overwrite the existing record — blank cells keep the original data.

Example: Upload a CSV with only "plate" and "status" columns — only the status will change for that bike, all other fields remain untouched.
